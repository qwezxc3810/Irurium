# 모바일 성능 검증

어항 화면이 휴대폰에서 부드럽게 도는지 재는 도구예요. **개발·검증 환경에서만** 보여요.

| 어디서 | 어떻게 열기 |
|---|---|
| 검증실 | `lab.html#perf` 또는 검증실 "성능 측정" 탭. 장면 3개(어린왕자 14일 · 꾸준형 100일 · 꾸준형 200일) |
| 앱 화면 | 개발 서버(`npm run dev`)이거나 주소 끝에 `?perf=1`. 지금 어항(데모)을 그대로 재요. 일반 주소에서는 패널이 없어요 |

## 보여 주는 값
| 값 | 뜻 |
|---|---|
| 평균 FPS | 1초에 화면을 몇 번 그렸는지(패널은 최근 2초, 측정 결과는 30초 전체) |
| 1% 느린 프레임 | 가장 느린 1% 프레임들의 평균 시간을 FPS로 바꾼 값. 끊김을 봐요 |
| 프레임 지연 | 프레임 시간 평균 · 99% · 최대, 33ms(30fps 아래)를 넘은 프레임 수와 비율 |
| 렌더링 해상도 | 기기 DPR → 실제로 쓴 렌더링 해상도, 캔버스 크기와 실제 픽셀 수 |
| 그리는 생물 | 렌더러가 화면에 그리고 있는 물고기·수초·수석·상징 수(엔진 상태와 같아야 해요) |

프레임 간격은 렌더러와 따로 `requestAnimationFrame`으로 재요. 다른 앱으로 넘어가 1초 넘게 멈춘 간격은 버리고 결과에 개수를 적어요.

## 일반 모드 vs 저사양 모드
같은 어항에서 버튼으로 바로 바꿔요(어항을 다시 만들지 않음).

| | 일반 | 저사양 |
|---|---|---|
| 렌더링 해상도 | 기기 DPR, 최대 2 | 최대 1 |
| 감정 조명 | 색 보정 필터(ColorMatrixFilter) | 필터 없이 반투명 덧칠 한 장 |
| 왼쪽 위 가산 빛 | 켬 | 끔 |
| 기포(화면 연출) | 최대 24개 | 최대 8개 |
| 빛줄기·별 반짝임 | 켬 | 끔(고정) |

**바꾸지 않는 것:** 생성 엔진, `ENGINE_VERSION`(0.2.0), 스냅샷, 물고기 수, 수초 수, 수석·상징 수, 배치. 품질 설정(`src/render/quality.ts`)에는 화면 연출 항목만 있고, 테스트가 이것과 골든 해시를 확인해요. 계정 설정으로 고정되는 값이 아니고, 측정 비교용이에요.

## 실제 휴대폰 값과 시뮬레이션 값 구분
결과 텍스트 맨 위 **"측정 출처"**로 구분해요.

| 측정 출처 | 조건 |
|---|---|
| ✅ 실제 휴대폰(측정자 확인) | 자동 판정이 휴대폰(휴대폰 브라우저 정보 + 터치)이고, 측정자가 "실제 휴대폰에서 재고 있어요"를 골랐을 때만 |
| ⚠️ 개발 환경 시뮬레이션 | 자동화·헤드리스 브라우저(측정자가 뭘 골라도), 또는 측정자가 "아니에요"를 고름 |
| ⚠️ 미확인 | 휴대폰으로 보이지만 측정자가 고르지 않음. 개발자 도구의 기기 흉내도 휴대폰처럼 보여서 자동 판정만 믿지 않아요 |

## 휴대폰에서 재는 순서
1. 휴대폰으로 검증실을 열고 "성능 측정" 탭으로 가요. 다른 앱은 닫고, 화면 밝기·절전 모드는 평소대로 둬요.
2. 장면을 고르고 일반 모드 → "30초 측정", 끝나면 저사양 모드 → "30초 측정".
3. 장면 3개 모두 반복해요(결과 6개).
4. "측정 기기"에서 **실제 휴대폰에서 재고 있어요**를 고르고 "결과 텍스트 복사". 자동 복사가 막히면 글상자를 길게 눌러 복사해요.
5. 기기 이름(예: 갤럭시 A15)도 함께 보내 주세요. 브라우저 정보에는 기종이 정확히 안 나올 수 있어요.
