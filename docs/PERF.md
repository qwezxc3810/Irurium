# 모바일 성능 검증

어항 화면이 휴대폰에서 부드럽게 도는지 재는 도구예요. **개발·검증 환경에서만** 보여요.

| 어디서 | 어떻게 열기 |
|---|---|
| 검증실 | `lab.html#perf` 또는 검증실 "성능 측정" 탭. 장면 3개(어린왕자 14일 · 꾸준형 100일 · 꾸준형 200일) |
| 앱 화면 | 개발 서버(`npm run dev`)이거나 주소 끝에 `?perf=1`. 지금 어항(데모)을 그대로 재요. 일반 주소에서는 패널이 없어요 |

## 보여 주는 값
| 값 | 뜻 |
|---|---|
| **어항 FPS** (1차 지표) | PixiJS가 어항을 **실제로 그린 프레임** 수. 렌더러 ticker에서 그리기(LOW 우선순위)가 끝난 뒤 UTILITY 우선순위로 시각을 기록해요. 패널은 최근 2초, 측정 결과는 측정 구간 전체 |
| 어항 1% 느린 프레임 | 어항 프레임 중 가장 느린 1%의 평균 시간을 FPS로 바꾼 값. 끊김을 봐요 |
| 어항 프레임 지연 | 어항 프레임 시간 평균 · 99% · 최대, 33ms(30fps 아래)를 넘은 프레임 수와 비율 |
| 렌더링 해상도 | 기기 DPR → 실제로 쓴 렌더링 해상도, 캔버스 크기와 실제 픽셀 수 |
| 그리는 생물 | 렌더러가 화면에 그리고 있는 물고기·수초·수석·상징 수(엔진 상태와 같아야 해요) |
| [진단] 브라우저 갱신 간격 | 렌더러와 따로 도는 `requestAnimationFrame` 간격. **어항이 그린 횟수가 아니에요.** 어항이 느리거나 멈춰도 화면 주사율 가까이 나올 수 있어서 성능 판정에 쓰지 않아요. 어항 FPS와 비교해 "어항 쪽이 병목인지" 볼 때만 써요 |
| [진단] 어항 갱신 제한 | 제한 없음 / 30fps / 15fps / 멈춤. 측정기가 어항 FPS를 제대로 잡는지 확인하는 용도. 평소에는 "제한 없음"으로 재고, 제한을 건 결과에는 경고가 붙어요 |

### 측정 방법
- "30초 측정"을 누르면 **2초 준비(워밍업)** 뒤 30초를 재요. 모드를 바꾼 직후의 흔들림을 빼기 위해서예요.
- 측정 구간은 시작~끝 시각으로 정하고, 그 안에서 끝난 프레임만 써요. 결과에는 **실측 시간**과 유효 프레임 시간을 같이 적어요(타이머가 조금 늦게 돌아도 구간 밖 프레임은 들어가지 않음).
- 측정 중에 화면이 숨겨지면(다른 앱, 화면 꺼짐) 숨김 구간을 빼고 결과를 **무효(참고용)**로 표시해요. 1초 넘는 간격도 멈춤으로 보고 버려요.
- 측정 중에 장면·모드·갱신 제한을 바꾸면 그 측정은 취소돼요.

## 일반 모드 vs 저사양 모드
같은 어항에서 버튼으로 바로 바꿔요(어항을 다시 만들지 않음).

| | 일반 | 저사양 |
|---|---|---|
| 렌더링 해상도 | 기기 DPR, 최대 2 | 최대 1 |
| 감정 조명 | 색 보정 필터(ColorMatrixFilter) | 필터 없이 반투명 덧칠 한 장 |
| 왼쪽 위 가산 빛 | 켬 | 끔 |
| 기포(화면 연출) | 최대 24개 | 최대 8개 |
| 빛줄기·별 반짝임 | 켬 | 끔(고정) |

**바꾸지 않는 것:** 생성 엔진, `ENGINE_VERSION`(0.2.0), 스냅샷, 물고기 수, 수초 수, 수석·상징 수, 배치. 품질 설정(`src/render/quality.ts`)에는 화면 연출 항목만 있고, 테스트가 이것과 골든 해시를 확인해요. 계정 설정으로 고정되는 값이 아니고, 측정 비교용이에요.

## 실제 휴대폰 값과 시뮬레이션 값 구분
결과 텍스트 맨 위 **"측정 출처"**로 구분해요.

| 측정 출처 | 조건 |
|---|---|
| ✅ 실제 휴대폰(측정자 확인) | 자동 판정이 휴대폰(휴대폰 브라우저 정보 + 터치)이고, 측정자가 "실제 휴대폰에서 재고 있어요"를 골랐을 때만 |
| ⚠️ 개발 환경 시뮬레이션 | 자동화·헤드리스 브라우저(측정자가 뭘 골라도), 또는 측정자가 "아니에요"를 고름 |
| ⚠️ 미확인 | 휴대폰으로 보이지만 측정자가 고르지 않음. 개발자 도구의 기기 흉내도 휴대폰처럼 보여서 자동 판정만 믿지 않아요 |

## 휴대폰에서 재는 순서
1. 휴대폰으로 검증실을 열고 "성능 측정" 탭으로 가요. 다른 앱은 닫고, 화면 밝기·절전 모드는 평소대로 둬요.
2. 장면을 고르고 일반 모드 → "30초 측정", 끝나면 저사양 모드 → "30초 측정".
3. 장면 3개 모두 반복해요(결과 6개).
4. 결과마다 **렌더링 해상도와 실제 픽셀이 모드에 따라 바뀌었는지** 봐요(예: 일반 DPR 3 → 2, 저사양 → 1). 안 바뀌면 저사양 모드가 그 휴대폰에서 해상도를 못 낮춘 거라 따로 알려 주세요.
5. "측정 기기"에서 **실제 휴대폰에서 재고 있어요**를 고르고 "결과 텍스트 복사". 자동 복사가 막히면 글상자를 길게 눌러 복사해요.
6. 기기 이름(예: 갤럭시 A15)도 함께 보내 주세요. 브라우저 정보에는 기종이 정확히 안 나올 수 있어요.
