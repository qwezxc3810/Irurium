# 흔적 생성 안내 · 감정 도감

감정 흔적(엔진 0.3.0)이 **어떤 마음에서 생겼는지 겪으며 익히도록** 돕는 앱 화면이에요. 근거는 1차 상징 평가 결과와 PR #27 후속 기획 리뷰(docs/SYMBOL_EVAL.md).

엔진·스냅샷은 바꾸지 않아요. 화면(UI)만 더해요(`src/ui/encyclopedia.ts`, `src/ui/EmotionGuide.tsx`). 0.2.0 어항에는 나타나지 않아요.

## 1. 흔적이 생기는 순간의 안내
- 기록을 저장해 흔적이 생기거나 자라면, 변화 카드 맨 위에 그림과 함께 짧은 안내가 붙어요.
  - 새로 생김: **"그리움이 유리병 편지가 되었어요"**
  - 자람: **"그리움이 더해져 유리병 편지가 자랐어요 · 2단계"**
  - 아래에 한 줄 의미, **기억 보기**(그 흔적의 기억 카드), **감정 도감**(그 칸을 강조해 열기) 버튼.
- **안내 문장에는 시간 표현(오늘·그동안·○일부터)을 넣지 않아요.** 여러 기록의 쪽수가 모여 생긴 흔적이나 미뤄졌다 놓인 흔적, 완독 채움을 특정 하루에서 생긴 것처럼 말하지 않기 위해서예요. 언제·어디서 왔는지는 바로 아래 엔진의 변화 문장이 출처 정책대로 말해요(예: "1월 1일부터 모인 그리움에서 …", "그동안의 평온이 모여 …").
- 새로 생김/자람은 문장을 읽지 않고 객체로 판단해요(흔적의 `bornSeq`가 이번 기록 순번이면 새로 생김).
- 한 변화에서 같은 흔적이 여러 번 자라면(완독 채움 등) 한 장으로 묶어 **"평온이 더해져 별빛 해파리가 2단계 자랐어요"** 처럼 말하고, 엔진 문장은 모두 이어 보여 줘요.
- 변화 카드는 **스냅샷 id**로 그 기록을 찾아요(배열 참조 비교 아님 → 저장·복원·복사 뒤에도 같음). 지난 기록의 '변화 보기'도 그 기록의 스냅샷 기준이에요.
- 그 흔적이 지금 어항에 없으면 '기억 보기' 버튼은 숨겨요.

## 2. 감정 도감
- 화면 위쪽 **'감정 도감'** 버튼으로 열고 닫아요. 외우라고 묻는 퀴즈·알림은 없어요. 필요할 때 펼쳐 보는 곳이에요.
- 12칸: 상징 그림 + 감정 이름(옛 이름) + 상징 이름 + 한 줄 의미 + **내 어항에 n개**.
- 그림은 **지금 화면에서의 1단계 실제 크기**예요(어항 논리 폭 1000 기준 표시 높이 × 화면 비율). 도감 칸 폭을 ResizeObserver로 재서 회전·리사이즈에도 맞춰요. 자라면 단계마다 조금씩 커져요. 실기기에서 어항 그림과 크기가 맞는지 확인이 남아 있어요.
- 한 줄 의미는 정답 암기용이 아니라 '왜 이 모양인지' 들려주는 말이에요. 문구는 기획자가 다듬어요.

## 3. 평가 화면과 분리
- 검증실(lab.html)의 평가 화면은 도감 모듈을 가져오지 않아요. 평가 도중 정답(의미 문구)이 보이지 않게 하려는 것이고, 테스트가 이를 확인해요(`src/ui/__tests__/encyclopedia.test.ts`).
- 예외: 24시간 기억 평가의 체험(B) 화면(`src/lab/ui/MemoryExposure.tsx`)은 일부러 도감을 보여 줘요. 노출 조건·횟수는 평가 기록에 남아요(docs/MEMORY_EVAL.md).
