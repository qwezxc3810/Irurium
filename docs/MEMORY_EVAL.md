# 감정 상징 기억 평가 (24시간)

검증실 `lab.html#mem`. PR #27 후속 기획 리뷰의 ③단계예요. **처음 보고 맞히기(첫인상)**와 **겪은 뒤 기억하기(학습·기억)**, **그때 일을 떠올리기(회상)**를 나눠서 봐요.

## 진행 순서 (같은 참여자)
| 단계 | 언제 | 내용 |
|---|---|---|
| A 첫인상 | 오늘 | 그림 14개(상징 12 + 대조 2)를 설명 없이 보고 마음 고르기 + 확신(찍었어요/아마도/확실해요) |
| B 체험 | A 직후 | 배정된 조건대로 노출 (아래 표) |
| C 다음 날 | B 끝나고 약 24시간 뒤 | 같은 14개를 새 순서로, 설명·도감 없이 다시 고르기 + 확신 + **"어제 체험 때 이 흔적과 함께 떠오르는 일이나 마음이 있나요?"** |

- 시작하면 참여자 코드(예: M87W)가 나와요. 이름은 받지 않아요. 다음 날 같은 기기에서 "이어서 하기"의 코드를 눌러요.
- C는 B 끝나고 **12시간이 지나야** 열려요. 권장은 20~30시간이고, 벗어나면 보고서에 표시만 해요(빼지 않음). 경과 시간은 그대로 기록해요.
- A·C 화면에는 상징 이름·정답·도감이 나오지 않아요. 도감 내용을 보여 주는 검증실 파일은 B 화면(`MemoryExposure.tsx`) 하나뿐이고, 테스트가 확인해요.
- 결과·정답은 진행자가 수집을 끝낸 뒤에만 열려요(상징 평가와 같은 방식). 끝나지 않은 참여자가 있으면 경고해요.

## 체험 조건 (B)
| 조건 | 내용 | 무엇과 비교하나 |
|---|---|---|
| 체험 | 마음을 4~8번 골라 그때마다 "그리움이 유리병 편지가 되었어요" 장면을 봄(앱의 흔적 생성 안내와 같은 형식, 의미 문구 없음) | 실제 앱 경험에 가장 가까움 |
| 도감 | 감정 도감 12칸(그림·이름·한 줄 의미)을 최소 20초 둘러봄 | 설명만으로 익히는 효과 |
| 체험 + 도감 | 둘 다 | |
| 노출 없음(대조) | B 없이 다음 날 C | **같은 그림을 두 번 본 효과**만 있는 기준선 |

- 기본은 자동 배정(인원이 가장 적은 조건부터). 진행자가 바꿀 수 있어요.
- 체험의 한마디는 그 순간을 떠올리는 데만 쓰고 **저장하지 않아요**(썼는지 여부만).

## 기록하는 것 (스키마 `irurium.memory-eval.v1`)
- 조건, A·C 답·확신·응답 시간, C 회상, B 노출(체험으로 생긴 상징 목록, 도감 연 횟수·머문 시간), B 끝 → C 시작 경과 시간
- 원본(JSON)을 복사해 다른 기기 기록과 합칠 수 있어요.

## 보는 법
- **정답률(상징 12종)**: 조건별 A → C, 모르겠어요, 확신. 대조 그림은 정답률에서 빼고 '대조에 감정을 고른 비율'로 따로 봐요.
- **회상**: 정답률과 별도 표. 또렷 / 어렴풋 / 안 떠오름 / 못 본 듯.
- **체험으로 생겼던 상징 vs 아니었던 상징**: 같은 사람 안에서 C 정답률·회상을 비교(체험 조건만).
- **다음 날에도 반복된 혼동**(2번 이상) → 선별 재디자인 후보.
- 3명은 탐색용이에요. C 정답률이 올라도 '노출 없음'과 비교하기 전에는 체험 효과라고 말하지 않아요.
- 최종적으로 보고 싶은 건 앱 속 실제 기록 회상이에요. 이 평가는 검증실 안의 짧은 체험이라 그 근사치예요.
