# 감정 상징 평가 (블라인드) — "이 상징은 어떤 마음일까?"

검증실 → **감정 상징 평가** 탭(`lab.html#sym`)이에요. 감정 흔적 상징 12종(PR #26)이 그림만 보고 어떤 마음인지 읽히는지 사람 눈으로 확인해요.

## 방법
- 그림을 하나씩 **14개** 보여 줘요. 상징 12종에 대조 그림 2개(송사리·둥근 수석, 감정과 무관)가 섞여 있고, 순서는 세션마다 무작위예요.
- 그림마다 "이 흔적은 어떤 마음에서 생겼을까요?"를 **12가지 마음 + 잘 모르겠어요** 중에서 골라요. 1~2분 걸려요.
- 큰 그림 아래에 **휴대폰 어항에서 보이는 크기(근사)**(논리 크기 × 0.38, 폭 1000 → 약 380px 가정)도 같이 보여 줘요. 기기마다 실제 크기는 달라요.
- **큰 그림과 휴대폰 크기 그림이 모두 뜨기 전에는 답할 수 없어요.** 불러오지 못하면 '다시 불러오기'가 나와요(안 보이는 그림에 답해 평가가 오염되지 않게).
- **결과·정답은 진행자가 수집을 끝낸 뒤에만 볼 수 있어요**(PR #27 재리뷰).
  - 평가를 모으는 동안에는 '결과 보기' 버튼이 없어요. 평가 전이든, 평가자 사이든 정답이 보이지 않아요.
  - 모든 평가자가 끝나면 진행자가 **'진행자: 수집 끝내고 결과 보기' → '네, 수집 끝내고 결과 보기'** 를 눌러요. 그때부터 결과·갤러리를 볼 수 있고, 새 평가는 시작할 수 없어요.
  - 더 받으려면 **'진행자: 수집 다시 열기'** 를 눌러요(결과는 다시 닫혀요). 이 기기에서 정답이 한 번 공개된 뒤 시작한 세션은 세션 목록과 보고서에 표시돼요. 정답을 본 사람이 아닌지 확인하고, 봤다면 빼 주세요.
- **블라인드**: 평가 중에는 그림 이름·정답을 보여 주지 않아요. 평가 중에는 정답 화면을 열 수 없어요. 다른 탭에 정답 화면이 열려 있으면 시작이 막히고, 평가 도중 정답 화면이 열렸던 세션은 판정에서 빠져요(V1과 같은 방식).
  - 이미지 파일 이름(예: `tear-pearl.webp`)은 개발자 도구로 볼 수 있어요. 평가자에게 개발자 도구를 열지 말라고 안내해 주세요.
- 결과는 이 기기에 저장돼요. 같은 휴대폰으로 차례로 하면 돼요. 다른 기기 평가는 원본(JSON)을 복사해 합칠 수 있어요.
- "화면 시험" 체크 세션과 끝까지 하지 않은 세션은 판정에서 빠져요.

## 결과 보기
- 상징 12종 전체 맞힌 비율(찍으면 약 8%), 모르겠어요 비율
- 대조 그림에 감정을 고른 비율: 높으면 아무 그림이나 감정으로 읽는 경향이에요.
- 상징별: 맞힘, 모름, **헷갈린 감정**(정답 말고 가장 많이 고른 감정), 탐색 판정
  - 잘 읽힘: 맞힘 50% 이상
  - 애매: 25~50%
  - 안 읽힘: 25% 미만
- **상징 12종 한눈에 보기**: 결과 화면(평가가 끝난 뒤)에서만 보여요. 12종을 큰 썸네일로 나란히 놓고 이름·정답 감정·맞힘·헷갈린 감정을 보여 줘요. 대조 2종은 따로예요. 실루엣끼리 비슷한 게 없는지 함께 봐요.
- **정리 텍스트 복사** → 기획자에게 붙여 주면 문서에 기록해요.

## 인원과 판단
- **집계 단위는 '유효한 평가 세션'이에요.** 별칭은 선택이라 같은 사람이 여러 번 했는지 자동으로 알 수 없어요. 서로 다른 사람이 한 번씩 하도록 진행자가 확인해 주세요(PR #27 리뷰).
- **유효 세션 3개 이상이면 결과를 보여 줘요. 다만 3명은 탐색용이에요.** 헷갈리는 상징과 혼동 패턴을 찾는 데 쓰고, 성공·출시 판단은 **5명 이상 별도 평가**로 정해요(PR #26 리뷰).
- 판정 기준(50%·25%)은 초안이에요. 결과를 보고 기획자가 확정해요.
